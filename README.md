# Unsupervised Learning and Reinforcement Learning Practical

## 📌 Overview

This repository contains a Python-based practical covering **Unsupervised Learning** and **Reinforcement Learning** using simple business examples.

The practical demonstrates how machine learning techniques can be applied to business problems, particularly **customer segmentation** and **delivery route selection**.

## 🎯 Learning Objectives

- Understand customer segmentation using K-Means Clustering.
- Group similar customers based on their behaviour.
- Visualize and interpret customer clusters.
- Understand the basic concepts of Reinforcement Learning.
- Identify agents, environments, actions, and rewards.
- Understand exploration and exploitation.

## 📚 Topics Covered

### 1. Customer Segmentation Using K-Means

The practical creates a customer dataset using:

- Monthly Spending
- App Visits

K-Means Clustering is applied to group customers into **3 clusters**.

The practical includes:

- Creating a customer dataset
- Selecting relevant features
- Applying K-Means clustering
- Grouping similar customers
- Visualizing customer clusters
- Interpreting customer segments
- Identifying possible business actions

### 2. Reinforcement Learning

A simple delivery-route example is used to explain Reinforcement Learning.

The practical covers:

- Agent
- Environment
- Action
- Reward
- Exploration
- Exploitation

The example demonstrates how a system can select a route based on the rewards received from previous actions.
